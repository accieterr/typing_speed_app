# Python Typing Speed Test

A terminal-based typing speed test built with Python and curses.

## Features
- 15 and 30 word tests
- Real-time WPM calculation
- Raw and net WPM
- Accuracy tracking
- Live green/red character feedback
- Random prompts generated from 300 common English words

## Running

python typing_speed_app.py

## Controls

1 - 15 word test
2 - 30 word test
Backspace - correct typed characters
Enter - finish test
Esc - exit
